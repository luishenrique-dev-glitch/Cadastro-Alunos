Cadastro-Alunos

Sistema web de cadastro e autenticação de usuários, desenvolvido como projeto prático de estudos em desenvolvimento Back-end.

Funcionalidades

Capturas de tela

Tela de cadastro



Tela de login

Cadastro de usuários.

Validação de nome, e-mail e senha.

Verificação de confirmação de senha.

Armazenamento de senhas com hash.

Login com validação de credenciais.

Autenticação por sessão com cookie.

Encerramento de sessão (logout).

Integração com banco de dados PostgreSQL.

Interface web com HTML, CSS e JavaScript.

Como executar localmente

Clone ou baixe o repositório.

Crie e ative um ambiente virtual Python.

Instale as dependências utilizadas pelo projeto.

Configure as variáveis de ambiente no arquivo .env.

Prepare o banco de dados PostgreSQL e a tabela necessária.

Inicie a API FastAPI.

Abra a interface pelo Live Server ou por um servidor web compatível.

Não publique credenciais, senhas ou chaves secretas no repositório.

Objetivo do projeto

Praticar desenvolvimento Back-end com Python, criação de APIs, integração com banco de dados relacional, validação de dados, hash de senhas e gerenciamento de sessões.

Status

Projeto desenvolvido para fins de aprendizado e evolução prática em desenvolvimento de software.
